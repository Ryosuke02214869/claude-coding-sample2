# ストップウォッチアプリ

シンプルで美しいストップウォッチアプリです。HTML、CSS、JavaScriptのみで作成されています。

## 機能

### 基本機能
- **時間計測**: 高精度な時間計測（ミリ秒単位）
- **スタート/ストップ**: 計測の開始と一時停止
- **リセット**: 計測時間のリセット
- **時間表示**: `HH:MM:SS.MS` 形式で見やすく表示

### ラップタイム機能
- **ラップタイムの記録**: 計測中に任意のタイミングでラップタイムを記録
- **最速/最遅ラップの強調表示**:
  - 最速のラップは緑色で表示
  - 最遅のラップは赤色で表示
- **リアルタイム表示**: 記録したラップタイムを逆順（最新が上）で表示
- **スムーズなアニメーション**: ラップタイム追加時のスライドインアニメーション

## デザイン

- モダンなグラデーション背景
- レスポンシブデザイン（モバイル対応）
- 直感的なボタンレイアウト
- 視認性の高いモノスペースフォント
- ホバーエフェクトとボタンアニメーション

## 使い方

1. **ブラウザで開く**
   ```bash
   # index.htmlをブラウザで開く
   ```

2. **計測を開始**
   - 「スタート」ボタンをクリックして計測を開始

3. **ラップタイムを記録**
   - 計測中に「ラップ」ボタンをクリックしてラップタイムを記録
   - 複数のラップタイムを記録可能

4. **計測を停止**
   - 「ストップ」ボタンをクリックして計測を一時停止
   - 「スタート」ボタンで再開可能

5. **リセット**
   - 「リセット」ボタンをクリックして計測時間とラップタイムをクリア

### キーボードショートカット

より効率的に操作できるキーボードショートカットを提供しています：

- **Enter（エンターキー）**: スタート/ストップの切り替え
  - タイマーが停止中の場合 → 計測を開始
  - タイマーが動作中の場合 → 計測を停止

- **Space（スペースキー）**: ラップタイムを記録
  - タイマーが動作中の場合のみ有効
  - 現在の計測時間をラップとして記録

## 特徴

- **軽量**: フレームワークやライブラリを使用していないため、非常に軽量

- **オフライン動作**: インターネット接続不要
- **カスタマイズ可能**: シンプルなコードで理解しやすく、カスタマイズが容易
