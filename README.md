# ストップウォッチアプリ

シンプルで美しいストップウォッチアプリです。HTML、CSS、JavaScriptのみで作成されています。

## デモ

このアプリはGitHub Pagesで公開されています：
**[デモを見る](https://Ryosuke02214869.github.io/claude-coding-sample2/)**

## 機能

### 基本機能
- **時間計測**: 高精度な時間計測（ミリ秒単位）
- **スタート/ストップ**: 計測の開始と一時停止
- **リセット**: 計測時間のリセット
- **時間表示**: `HH:MM:SS.MS` 形式で見やすく表示

### ラップタイム機能
- **ラップタイムの記録**: 計測中に任意のタイミングでラップタイムを記録
- **最速/最遅ラップの強調表示**:
  - 最速のラップは緑色で表示
  - 最遅のラップは赤色で表示
- **リアルタイム表示**: 記録したラップタイムを逆順（最新が上）で表示
- **スムーズなアニメーション**: ラップタイム追加時のスライドインアニメーション

## デザイン

- モダンなグラデーション背景

## 使い方

1. **ブラウザで開く**
   ```bash
   # index.htmlをブラウザで開く
   ```

2. **計測を開始**
   - 「スタート」ボタンをクリックして計測を開始

3. **ラップタイムを記録**
   - 計測中に「ラップ」ボタンをクリックしてラップタイムを記録
   - 複数のラップタイムを記録可能

4. **計測を停止**
   - 「ストップ」ボタンをクリックして計測を一時停止
   - 「スタート」ボタンで再開可能

5. **リセット**
   - 「リセット」ボタンをクリックして計測時間とラップタイムをクリア

### キーボードショートカット

より効率的に操作できるキーボードショートカットを提供しています：

- **Enter（エンターキー）**: スタート/ストップの切り替え
  - タイマーが停止中の場合 → 計測を開始
  - タイマーが動作中の場合 → 計測を停止

- **Space（スペースキー）**: ラップタイムを記録
  - タイマーが動作中の場合のみ有効
  - 現在の計測時間をラップとして記録

- **Backspace（バックスペースキー）**: リセット
  - 計測時間とすべてのラップタイムをクリア
  - タイマーの動作状態に関わらずいつでも実行可能

## GitHub Pagesへのデプロイ

このプロジェクトはGitHub Actionsを使用して自動的にGitHub Pagesにデプロイされます。

### 初回設定

1. **GitHub Pagesを有効化**
   - リポジトリの `Settings` → `Pages` に移動
   - `Source` で `GitHub Actions` を選択

2. **デプロイ方法**

   以下のいずれかの方法でデプロイが実行されます：

   **自動デプロイ（push時）**
   - `main` または `master` ブランチにpushすると自動的にデプロイ

   **手動デプロイ**
   - GitHubリポジトリの `Actions` タブを開く
   - `Deploy to GitHub Pages` ワークフローを選択
   - `Run workflow` ボタンをクリック

3. **デプロイ状況の確認**
   - `Actions` タブでワークフローの実行状況を確認
   - 完了後、`https://<username>.github.io/<repository-name>/` でアクセス可能

### ワークフローの詳細

`.github/workflows/deploy.yml` には以下の設定が含まれています：
- **トリガー**: push（main/masterブランチ）または手動実行
- **権限**: GitHub Pagesへのデプロイに必要な権限を自動設定
- **デプロイ**: リポジトリのルートディレクトリを直接デプロイ
